# 🎨 럭셔리 상세페이지 생성기 (Premium Detail Page Generator)

대충 찍은 상품 사진과 간단한 검색어만 있으면, AI가 **스튜디오급 고해상도 명품 사진**과 **매력적인 마케팅 문구**를 자동으로 생성하여 완벽한 쇼핑몰 상세페이지를 만들어주는 Streamlit 기반 웹 애플리케이션입니다.

## ✨ 주요 기능
- **사진 퀄리티 업그레이드 (Image-to-Image):** 휴대폰으로 찍은 사진을 최고급 스튜디오 환경의 8K 럭셔리 화보처럼 변환합니다. (Gemini 2.5 Flash Image 활용)
- **마케팅 문구 자동 작성:** 인터넷 검색 결과를 기반으로 상품에 어울리는 최적의 카피라이팅을 자동으로 작성합니다.
- **스토리텔링 블록:** 사진과 텍스트를 번갈아 배치하여 몰입감 있는 스토리를 구성할 수 있습니다.
- **클릭 한 번으로 저장:** 완성된 상세페이지를 하나의 깔끔한 이미지(PNG, JPG)로 다운로드할 수 있습니다.
- **작업 보관함 기능:** 만들었던 프로젝트를 안전하게 폴더에 자동 저장하고 언제든 다시 불러올 수 있습니다.

## 🚀 실행 방법
가상환경 세팅 및 라이브러리 설치부터 실행까지 한 번에 자동화되어 있습니다.
1. `실행하기(더블클릭).bat` 파일을 실행합니다.
2. 검은색 콘솔 창이 뜨며 필요한 패키지가 자동 설치됩니다.
3. 잠시 후 기본 브라우저가 열리며 프로그램이 시작됩니다.

## ⚙️ 요구 사항
- Python 3.8 이상
- Google Gemini API 키 (앱 내 사이드바에서 입력 및 저장 가능)

## 📌 주의사항
- `saved_products` 폴더에 고객님의 작업물이 저장됩니다.
- API 키가 포함된 파일(`api_key.txt`)은 Github에 동기화되지 않도록 `.gitignore`에 처리되어 있습니다.
